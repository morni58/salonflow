# Peperon — материалы по дизайну SalonFlow (frontend)

Здесь собрано всё, что нужно, чтобы **переделать визуал** на более мягкий и приятный: где лежат файлы, какие переменные темы, копия глобальных стилей.

## Как пользоваться

1. Читай `DESIGN_MAP.md` — карта экранов и компонентов.
2. Читай `TOKENS_AND_THEME.md` — цвета, шрифты, как подставляются цвета салона из базы.
3. Основной файл стилей в проекте: `frontend/src/index.css` (здесь же лежит копия `reference-index.css`).
4. После правок правь файлы в **`frontend/`**, а эту папку можно держать как **референс и заметки** (она не участвует в сборке сайта).

## Быстрый старт после редизайна

- Глобальные стили и анимации: `frontend/src/index.css`
- Шрифты и meta: `frontend/index.html`
- Тема салона (динамические CSS-переменные): `frontend/src/hooks/useTenant.ts` → функция `applyTheme`
- Корневой layout страницы: `frontend/src/App.tsx`

---

Папка **peperon** — только документация и снимок стилей; деплой и `npm run dev` используют код из **`frontend/`**.
