# Идеи для более нежного и спокойного UI

Не обязательный список — для вдохновения при редизайне в **peperon**-стиле.

- **Палитра:** кремовый / тёплый белый фон вместо глубокого `#0f172a`, пыльный розовый или лавандовый вместо насыщенного фиолетового; акцент — приглушённый коралл или персик.
- **Контраст:** избегать чистого чёрного текста — использовать тёмно-серый или коричневато-серый.
- **Карточки:** больше белого/кремового с лёгкой тенью вместо тёмного glass; или оставить glass, но с **более высокой прозрачностью** и мягкой границей.
- **Скругления:** единый радиус (например `rounded-2xl` / `rounded-3xl`) для кнопок и карточек.
- **Типографика:** можно сменить пару на что-то с более «ручным» характером для заголовков (например **Fraunces**, **Cormorant**) + Inter для текста — подключить второй шрифт в `index.html`.
- **Герой:** меньше контрастных орбов; мягкий градиент или очень лёгкая текстура.
- **Кнопки:** мягкая тень, без резкого неона; hover — лёгкое затемнение/осветление.

Все изменения вносятся в код **`frontend/`**; здесь только заметки.
